NOT part of the build (PlatformIO only compiles src/).

Parked work from the "hardened" build: verifying GitHub's TLS certificate for OTA downloads by
embedding a small set of root CAs (ca_bundle.h, ~11 KB, generated by gen_ca_bundle.py).
OTA downloads currently use setInsecure() exactly as in v1.0.1.14 (traffic is encrypted but
the server's identity is not checked).

To re-enable later: copy ca_bundle.h back to include/, and in src/modules/mqtt_ota.inc replace the
two "client.setInsecure()" blocks with client.setCACert(OTA_CA_BUNDLE) (and require NTP to have
synced first, because certificate dates can't be checked without the time).
